# Диагностика сетевых интерфейсов и анализ ARP-кэша

## Task

Шаг 1. Исследуем свои сетевые карты

- Windows: `ipconfig /all`
- Linux: `ip a` или `ifconfig`

Что нужно найти в выводе:
0. Разобрать формат вывода
1. Найди свою активную сетевую карту (обычно называется Беспроводная сеть / Wi-Fi или Ethernet / Подключение по локальной сети).
2. Выпиши свой IPv4-адрес.
3. Выпиши свой Физический адрес (MAC-адрес).
4. Выпиши IP-адрес своего Основного шлюза (Default Gateway) — это адрес твоего домашнего роутера.

Шаг 2. Исследуем ARP-кэш твоего компьютера

- `arp -a`

Что нужно сделать:
1. Посмотри на список. Ты увидишь таблицу со столбцами «Интернет-адрес» (IP) и «Физический адрес» (MAC).
2. Найди в этом списке IP-адрес своего Основного шлюза (который ты подсмотрел в Шаге 1).
3. Убедись, что твой компьютер знает его физический MAC-адрес (тип записи должен быть «динамический»).

## Solution

Шаг1.
1. `ifconfig` - список сетевых карт
- lo = localhost
- eht0 = моя сетевая карта
- mtu = maximum transition unit = макс. размер пакета в байтах
- inet = мой ip  
- netmask = маска сети
- broadcast = широковещательный 
- inet6 = мой ipv6
- ether = MAC адрес 
- RX = Recieve = полученные пакеты
- TX = Transmit = отправленные пакеты

тут все понятно
